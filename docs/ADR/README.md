# Architecture Decision Records

Add an ADR when a change alters architecture, scoring semantics, evidence semantics, eligibility gates, data contracts, generated-project policy, or source trust assumptions.

## Naming

```text
ADR-YYYYMMDD-short-title.md
```

## Template

```text
# ADR-YYYYMMDD Title

## Status

Proposed / Accepted / Superseded

## Context

What decision is needed and why?

## Decision

What did we choose?

## Consequences

What improves, what gets worse, what must be monitored?

## Rollback

How can this decision be reversed?
```
