# Mental Models

## Radar, Not Autopilot

The system finds and ranks opportunities. It does not decide to enter, publish, or submit on behalf of the human.

## Evidence Ledger

Every high-value field should be treated like a claim with provenance. The model value is only as trustworthy as its best evidence.

## Gates Before Scores

Eligibility, AI policy, deadline, and human-review gates protect the workflow before ranking optimism can take over.

## Spec Factory

`build-spec` produces a project package for another build pass. It is a controlled handoff, not proof that a project exists.

## Calibration Loop

Results become learning signals. Calibration should suggest changes, but humans approve score changes because weights encode strategy.

## Docs As External Memory

Long AI sessions will compress. Repo docs, tests, and artifacts keep the project from forgetting what matters.
