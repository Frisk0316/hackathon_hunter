# CRITIQUE_PROTOCOL


Before implementing a non-trivial idea, answer:

1. What assumption is the user making?
2. What could be wrong with this assumption?
3. What are 3 alternative solutions?
4. What is the simplest test to validate the idea?
5. What is the failure mode if this idea is wrong?
6. What would a senior engineer / researcher / product owner object to?
7. Should we implement now, prototype first, or reject?

The AI should not be adversarial for its own sake, but must not merely comply when the request has hidden risk.
